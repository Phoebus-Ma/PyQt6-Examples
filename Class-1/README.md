
# Introduction

Class-1 is PyQt6 control examples.


# Enviorment

```bash
$ python -m pip install --upgrade pip
$ pip install pyqt6
```

in China:

```bash
$ python -m pip install --upgrade pip
$ pip install pyqt6 -i https://pypi.tuna.tsinghua.edu.cn/simple
```


# Usage

Example dial:

```bash
$ cd PyQt6-Examples/Class-1/Dial
$ ls
main.py  MainWindow.py

$ python main.py
```
